# incoming

Media that has arrived but does not belong to an article yet.

Drop new artwork here while a piece is being written, then file it: move it
into `public/assets/posts/<slug>/`, rename it `cover.png` or `01.png`, `02.png`
in the order it appears in the article, and point the markdown at it.

Nothing here is referenced by the site. If a file has sat here long enough that
nobody remembers what it was for, delete it.
